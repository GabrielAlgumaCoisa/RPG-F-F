# Fumaça e Feitiço

a tabletop fantasy RPG, presented as a small website.

# Live site:
https://gabrielalgumacoisa.github.io/RPG-F-F/

## About the game

Fumaça e Feitiço is an original tabletop role-playing game set in a world where magic has stopped being a secret and become part of everyday life. It lives in the same streets as factories, back alleys and street-corner hustles, and it leaves a mark on everyone who gets close to it.

The tone is gritty, a little ironic, and always a bit lived-in, closer to a well-worn notebook than a polished rulebook.

## About this site

The site gathers the game's reference material in one place, written for the people sitting around the table: the players and whoever runs the game. It is a work in progress, and pages may change or grow over time.

## Built with

- HTML
- CSS
- [Google Fonts](https://fonts.google.com/)

This is also a learning project: a hands-on way to practice building web pages from scratch.
